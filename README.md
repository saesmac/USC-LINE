# USC_LINE

## Estrutura do projeto

- apps/web/: aplicações front-end e painéis
  - painel-atendente/
  - usc_line/
- apps/desktop/: projetos desktop e executáveis
  - AtendenteWindows/
  - unisagrado-exe/
- backend/: backend em C#
  - Backend/
- docs/: materiais de entrega, correções e instruções
  - correcao-relatorios/
  - entrega-unisagrado/
- archive/zips/: ZIPs e artefatos antigos

A organização foi agrupada por finalidade para facilitar navegação e manutenção do repositório.
